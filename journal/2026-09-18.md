# 📔 Quest Logs: Introduction to C & Memory Mechanics

## 🧠 What I Learnt

### 1. The Core Philosophy of C
* **Hardware-First Language:** C was built alongside the UNIX operating system. It does not hide the hardware from you. It deals directly with what computer processors natively understand: **characters, numbers, and memory addresses**.  

* **The Programmer is King:** C assumes you know exactly what you are doing. It provides no automatic safety guards. If you write bad code that accesses restricted hardware memory, C will let you run it, even if it crashes the system.

* **No Built-in I/O:** The core C language cannot print text to a screen or read a file on its own. It relies entirely on external **Standard Libraries** (like `<stdio.h>`) to communicate with the outside world.

### 2. Typeless vs. Typed Languages

* Older ancestors of C (like B and BCPL) were **"typeless"**—everything was just one giant bucket of bits.
* C introduced **Data Types** (`int`, `char`, `float`). This allows the programmer to specify exactly how much memory space a variable needs on a hardware chip.

### 3. The Embedded Superpower: No Garbage Collection 🔌
* **Modern Languages (Java/Python):** Use a background automation program called a **Garbage Collector** to constantly scan and sweep unused memory from the **Heap**.
* **The Catch:** This automatic cleaning causes unpredictable microsecond pauses (lacks Real-Time Determinism), which is deadly for critical systems like drone stabilizers or car braking units.
* **The C Advantage:** C has **no automatic cleaner**. Memory management is completely **manual** using functions like `malloc()` and `free()`. Because there is no background software running, C code runs at raw, lightning-fast hardware speed with zero unexpected delays.
