# C Quest

An eight-week record of learning C through *The C Programming Language*.
Each entry captures what I studied, what I built, and what I need to revisit.

## Source

*The C Programming Language*, 2nd ed. Brian W. Kernighan and Dennis M. Ritchie.
Prentice-Hall, 1988.

## Purpose

- Study one focused part of the book each day.
- Implement and test the book's exercises.
- Record mistakes and corrections so the notes remain useful later.
